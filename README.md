# AquaPro — Swimming Academy & Aquatic Center

A multipurpose, responsive HTML template for swimming academies, aquatic centres, clubs, and water-wellness businesses. Built with semantic HTML, Tailwind CSS (the original academy pages), and a lightweight shared CSS/JavaScript layer for the additional commercial pages.

## Page map

- `index.html` — primary academy landing page
- `home-agency.html` — alternate premium / niche-service home
- `about.html`, `programs.html`, `program-details.html`, `coaches.html`
- `batch-timings.html`, `facilities.html`, `pricing.html`, `contact.html`
- `blog.html`, `blog-details.html`
- `admin-dashboard.html`
- `login.html`, `register.html`, `maintenance.html`, `404.html`

## Included interactions

- Light/dark mode and LTR/RTL preferences persisted in the browser
- Responsive mobile navigation on original academy pages
- Programme and schedule filters, accordions, trial/contact forms
- Filterable/searchable Journal, counters, auth and maintenance form demos
- Dashboard metrics and recent enrollment table

All forms are client-side demos: connect them to your chosen backend, CRM, payment provider, or email service before production use. Replace the sample copy, phone number, map, and pricing with client content.
